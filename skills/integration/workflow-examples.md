# Workflow Examples

## 职责

沉淀可演示、可复现的业务工作流，说明系统如何辅助网格员完成真实任务。

## 当前实现位置

- `README.md`：描述政策咨询、工单填报、重点人群走访和日常复盘场景。
- `demo/low_income_policy_demo.txt`：政策咨询演示文档。
- `frontend/src/pages/`：各业务页面入口。
